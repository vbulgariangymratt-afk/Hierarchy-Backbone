# Saved Background Color

The background color used for the distraction-free "New Life Area" setup page is:

- **HEX**: `#0f0f11`
- **RGB**: `rgb(15, 15, 17)`
- **RGBA (with 95% opacity)**: `rgba(15, 15, 17, 0.95)`

This color is loved by the user and can be integrated into solid dark mode in the future.
